### 발견한 결함과 조치 (2026-10-10 수정 완료)

1. **모달 Drawer·시트에 포커스 트랩이 없었다.** `aria-modal="true"`인 Drawer에서 Tab을 계속 누르면 뒤쪽 페이지로 포커스가
   나갔다. 공통 훅 `src/hooks/useFocusTrap.ts`를 추가해 `DestinationDrawer`, `SafetyDrawer`, `MobileNavSheet`에 적용했다.
   상세 Drawer 위에 안전정보 Drawer가 겹쳐 열려도 각자 안에서만 순환하고, Esc는 위 패널부터 닫힌다.
2. **모바일 메뉴 시트를 닫으면 포커스가 사라졌다.** 시트를 닫을 때 메뉴 버튼으로 포커스를 돌려 주도록 고쳤다.

- 수정 후 검증: Production 빌드 서버에서 Tab 30회·Shift+Tab 30회 이동이 모두 모달 안에 머무는지, Esc 후 포커스가 눌렀던 요소로
  돌아오는지 키보드 입력으로 확인했다. 기존 E2E(공개 Smoke, 여행 도구, 인증 비로그인)는 11개 통과, 3개 skip(로그인 계정 없음).
- `MateDetailPanel`(`/mates` 동행글 상세)은 `aria-modal`이 아닌 보조 패널이라 이번 수정 대상에서 제외했다.
- 이 검증은 임시 스펙으로 실행했고 저장소에는 영구 테스트로 남기지 않았다.
