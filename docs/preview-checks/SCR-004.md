## 승인 시점의 알려진 한계

- 실제 Supabase 연결과 시드 데이터가 없는 환경에서는 목록이 오류 또는 Empty로 보일 수 있어, 카드 선택·상세·참가 요청 흐름은 데이터가 있어야 확인된다.
- 페이지 메타데이터는 `layout.tsx` 기본값을 쓴다(page.tsx가 클라이언트 컴포넌트).
- 연령대·성별·모집 상태 필터는 데이터가 없어 제공하지 않는다.
- 이미 차단한 상대의 글에서도 차단 버튼이 처음에는 "차단하기"로 보일 수 있다.
- 필터·목록은 브라우저에서만 그려진다(서버 HTML에는 없음).
