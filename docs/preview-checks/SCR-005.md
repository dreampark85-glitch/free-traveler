## 승인 시점의 알려진 한계

- 로그인 이후 화면(프로필·내 활동·관리자 탭)은 실제 Supabase 연결과 계정이 없는 환경이라 렌더링을 확인하지 못했다.
- 가입·이메일 인증·로그인·로그아웃·비밀번호 재설정의 실제 동작은 확인하지 못했다(Supabase Redirect URL·이메일 템플릿 설정 필요).
- 관리자 탭은 `user_profile.role`을 ADMIN으로 바꾼 계정이 있어야 볼 수 있다(service role로만 가능).
- 프로필 저장·성인 확인은 서버 API 없이 RLS로 보호된 직접 쓰기이며 서버 측 zod 검증이 없다. 성인 확인은 자기 선언이다.
